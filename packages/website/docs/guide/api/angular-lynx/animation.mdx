# Animation

| Export                 | Kind  | Description                                                                                                                                                                                 |
| ---------------------- | ----- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `LynxAnimation`        | Class | Represents a running animation on a Lynx element. Created via `element.animate()`. Provides `play()`, `pause()`, and `cancel()` methods.                                                    |
| `LynxAnimationOptions` | Type  | Options for animation timing and behavior. Accepts both Web Animations API naming (`iterations`, `easing`, `fill`) and Lynx-native naming (`iterationCount`, `timingFunction`, `fillMode`). |

## Enter/Leave Transitions

| Export                | Kind      | Description                                                                                                                                                                                                                                                                                                                                         |
| --------------------- | --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `LynxTransition`      | Component | Animates content enter/leave using CSS transition classes (same convention as Vue's `<Transition>`). Inputs: `show` (boolean), `name` (class prefix, default `'v'`), `duration` (ms, default `300`). Outputs: `afterEnter`, `afterLeave`. Manages `shouldRender` internally — content is removed only after the leave animation ends.               |
| `LynxTransitionGroup` | Component | Animates list items entering/leaving using the same CSS class convention. Manages its own views via `ViewContainerRef` so it can delay removal for leave animations. Inputs: `each` (T[]), `trackBy` ((item: T) => unknown), `name`, `duration`. Outputs: `afterEnter(T)`, `afterLeave(T)`. No move/FLIP animations (background-thread limitation). |
