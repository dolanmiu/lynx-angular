# &lt;input&gt;

:::tip
Add `imports: [LYNX_ELEMENTS]` from `@blotch/angular-lynx` to your component for intellisense, autocomplete, and type safety.
:::

Single-line text input field.

<Go example="element-input" defaultFile="src/app/app.ts" />

```angular-html
<input
  type="text"
  placeholder="Enter your name"
  (bindinput)="onInput($event)"
/>
```

The input event provides the value via `event.detail.value`:

```typescript
onInput(event: { detail: { value: string } }): void {
  this.name.set(event.detail.value);
}
```
