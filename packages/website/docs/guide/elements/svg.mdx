# &lt;svg&gt;

:::tip
Add `imports: [LYNX_ELEMENTS]` from `@blotch/angular-lynx` to your component for intellisense, autocomplete, and type safety.
:::

Displays SVG graphics via the `content` attribute (not inline SVG markup).

<Go example="element-svg" defaultFile="src/app/app.component.ts" />

```angular-html
<svg [attr.content]="svgString" style="width: 80px; height: 80px;" />
```
