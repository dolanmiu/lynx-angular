# Host Data

Lynx apps receive data from the native host — initial card/page data, shared properties like theme or locale, and processor pipelines that transform raw payloads before they reach your components. AngularLynx exposes all of this through injectable services backed by Angular signals.

<Go example="data-flow" defaultFile="src/app/app.component.ts" />

| Service / API              | Purpose                                                               |
| -------------------------- | --------------------------------------------------------------------- |
| `LynxInitDataService`      | Per-card initialization data passed by the host at creation time      |
| `LynxGlobalDataService`    | Host-level data shared across all Lynx cards (theme, locale, etc.)    |
| `registerDataProcessors()` | Transform raw native payloads before they reach `LynxInitDataService` |
