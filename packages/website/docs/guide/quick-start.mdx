# Quick Start

This guide walks you through creating an AngularLynx app from scratch and running it on your device.

## Prerequisites

- Angular 21+
- [Official documentation as to what Angular needs](https://angular.dev/reference/versions)

## Create a New Project

### 1. Initialize the project

```bash
mkdir my-lynx-app && cd my-lynx-app
npm init -y
```

### 2. Install dependencies

```bash
# Angular core
npm install @angular/core @angular/common @angular/platform-browser @angular/compiler

# AngularLynx renderer
npm install @blotch/angular-lynx

# Build tooling
npm install -D @blotch/rsbuild-plugin-angular-lynx @lynx-js/rspeedy typescript
```

If you want routing (most apps do):

```bash
npm install @angular/router
```

### 3. Create the build configuration

```typescript title="lynx.config.ts"
import { pluginAngularLynx } from '@blotch/rsbuild-plugin-angular-lynx';
import { defineConfig } from '@lynx-js/rspeedy';

export default defineConfig({
  source: {
    entry: './src/main.ts',
  },
  plugins: [pluginAngularLynx()],
});
```

### 4. Create the entry point

```typescript title="src/main.ts"
import { bootstrapApplication } from '@blotch/angular-lynx';
import { AppComponent } from './app/app.component';
import { appConfig } from './app/app.config';

bootstrapApplication(AppComponent, appConfig);
```

### 5. Create the app configuration

```typescript title="src/app/app.config.ts"
import {
  type ApplicationConfig,
  provideZonelessChangeDetection,
} from '@angular/core';
import { provideRenderer } from '@blotch/angular-lynx';

export const appConfig: ApplicationConfig = {
  providers: [provideZonelessChangeDetection(), provideRenderer()],
};
```

### 6. Create the root component

```typescript title="src/app/app.component.ts"
import { Component, signal } from '@angular/core';
import { LYNX_ELEMENTS } from '@blotch/angular-lynx';

@Component({
  selector: 'app-root',
  standalone: true,
  imports: [LYNX_ELEMENTS],
  template: `
    <view class="container">
      <text class="title">Hello, {{ name() }}!</text>
      <view class="button" (bindtap)="greet()">
        <text class="button-text">Tap me</text>
      </view>
    </view>
  `,
  styles: [
    `
      .container {
        display: flex;
        flex-direction: column;
        align-items: center;
        justify-content: center;
        height: 100vh;
      }
      .title {
        font-size: 24px;
        font-weight: bold;
        margin-bottom: 16px;
      }
      .button {
        background-color: #dd0031;
        padding: 12px 24px;
        border-radius: 8px;
      }
      .button-text {
        color: white;
        font-size: 16px;
      }
    `,
  ],
})
export class AppComponent {
  name = signal('AngularLynx');

  greet(): void {
    this.name.set('World');
  }
}
```

## Run the Dev Server

```bash
npx rspeedy dev
```

The terminal will display several URLs:

- **Web Preview** — Open this in your browser to see the app rendered as a web page
- **Lynx Bundle** — URL for loading in Lynx Explorer on a native device
- **QR Code** — Scan with Lynx Explorer to load the app on your phone

## Preview on a Native Device

To see your app running as a true native experience, use [Lynx Explorer](https://lynxjs.org/guide/start/quick-start.html#setting-up-the-development-environment):

1. **iOS Simulator** — Download the Lynx Explorer app for your Mac's architecture from the [Lynx releases](https://github.com/nichenqin/nichenqin.github.io/releases)
2. **Android** — Download the APK from the same releases page and install on your device or emulator
3. Scan the QR code shown in the terminal, or enter the bundle URL manually

:::tip
The QR code plugin (`@lynx-js/qrcode-rsbuild-plugin`) can be added to your `lynx.config.ts` to display a scannable QR code in the terminal during development. See the [kitchen-sink-app](https://github.com/nichenqin/angular-lynx/tree/master/packages/kitchen-sink-app) for an example.
:::

## Adding Routing

To add navigation between views, install `@angular/router` and use `provideRouter`:

```typescript title="src/app/app.config.ts"
import {
  type ApplicationConfig,
  provideZonelessChangeDetection,
} from '@angular/core';
import { provideRenderer, provideRouter } from '@blotch/angular-lynx';
import { routes } from './app.routes';

export const appConfig: ApplicationConfig = {
  providers: [
    provideZonelessChangeDetection(),
    provideRenderer(),
    provideRouter(routes), // [!code highlight]
  ],
};
```

```typescript title="src/app/app.routes.ts"
import type { Routes } from '@angular/router';

export const routes: Routes = [
  { path: '', pathMatch: 'full', redirectTo: 'home' },
  {
    path: 'home',
    loadComponent: () =>
      import('./home/home.component').then((m) => m.HomeComponent),
  },
];
```

See the [Routing guide](/guide/routing) for details on navigation patterns and the in-memory location strategy.

## Project Structure

```
my-lynx-app/
  lynx.config.ts              # RSpeedy build configuration
  src/
    main.ts                    # Entry point (bootstrapApplication)
    app/
      app.config.ts            # Providers (zoneless CD, renderer, router)
      app.component.ts         # Root component with Lynx elements
      app.routes.ts            # Route definitions (optional)
```

## What's Different from Web Angular?

| Concept          | Web Angular                | AngularLynx                   |
| ---------------- | -------------------------- | ----------------------------- |
| Bootstrap        | `bootstrapApplication()`   | `bootstrapApplication()`      |
| Renderer         | Browser DOM                | Lynx native elements          |
| Elements         | `<div>`, `<span>`, `<img>` | `<view>`, `<text>`, `<image>` |
| Events           | `(click)`, `(input)`       | `(bindtap)`, `(bindinput)`    |
| Change detection | Zone.js or zoneless        | Zoneless only                 |
| Router           | URL-based                  | In-memory                     |
| Build tool       | Angular CLI / esbuild      | RSpeedy (Rsbuild)             |
